# Engine sliders: source registry

Snapshot: `d75e87dd4cdef9003b26e6e982b73e722a0d19d2`. Lines refer to this revision. Defaults below are code defaults, not the effective values of an installed app or a particular take. Settings are resolved into a runtime snapshot; environment overrides can win. The registry distinguishes adjustable settings from fixed engineering parameters: a catalog range is not proof of a safe or wired UI control. See `ENV_REGISTRY.toml` for environment lifecycle and `HOTKEYS_CONTRACT.md` for gesture behavior.

`utterance_silence_sec` in the live log is a resolved session input, not another setting: hands-free uses `toggle_silence_sec`, agent-channel uses its resolved send pause, and single-turn uses `None` (`core/audio/streaming_recorder.rs:80`, `app/controller/agent_channel.rs:539`). Missing `agent_channel` settings default independently; repair does not seed them from toggle silence (`core/config/repair.rs:219`). The environment registry and hotkey contract agree with that split.

For ledger position `p`, clamp to [-100, 100], let `share = abs(p)`. Starting at `(repeat, near) = (100, 500)` ms, interpolate by integer arithmetic `from ± abs(to-from)*share/100`: for negative positions the endpoint is `(160, 250)`, for positive `(60, 1000)` (`core/pipeline/engine_tuning.rs:148`). The log about moving word admission means these derived thresholds differ from the default, not that the acoustic ledger has acquired a separate text identity rule.
