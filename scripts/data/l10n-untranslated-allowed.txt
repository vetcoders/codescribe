# Keys allowed to carry `shouldTranslate: false` in the String Catalogs —
# which skips them entirely, not just the identical-to-source check: no
# language owes them a translation and the coverage gate never sees them.
#
# Checked by scripts/l10n-lint.py (make verify-l10n-catalog, part of make
# check). The flag used to be free: a key could be marked untranslatable with
# no record of why, so 23 user-visible strings — including Settings labels
# like "Text formatting" and "Fixed windows" — shipped English-only without a
# trace. This file is the trace. A key marked `shouldTranslate: false` must
# be named here with the reason; a name here that no catalog still flags is a
# stale allowance and must be dropped.
#
# A line is one key, exactly as the catalog spells it; `#` starts a comment,
# so a key containing `#` cannot be listed. A blank line separates groups and
# is never a key, so `(empty string)` stands in for the one real key that is
# itself empty (scripts/l10n-lint.py: EMPTY_KEY_MARKER). Listing a key here is
# not a judgment that it should stay untranslated forever — it records
# today's flag so the gate can see it. Each key below is its own English
# text; every group states why it is flagged and, where a screen shows it,
# which files. Which of them should translate after all is an open founder
# decision, tracked in docs/LOCALIZATION_LEDGER.md.
#
# Format-only and empty keys — string interpolation produces these as a
# literal key; there is no word in them to translate.
